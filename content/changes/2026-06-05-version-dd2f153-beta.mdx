> **Staging release** — try it at [staging.arcanetable.app](https://staging.arcanetable.app/).

## Features

- **Settings menu** — there's now a Settings option in the in-game menu. Currently it houses the camera tilt toggle, with more options to come.
- **Camera tilt is now opt-in** — the head-tilt camera effect from the previous build is off by default. Enable it in Settings if you want it.

## Fixes

- **Hand card overlay** — card action menus were appearing in the wrong position when hovering cards in hand. Fixed.
- **Battlefield drag** — a regression from the previous build caused cards on the battlefield to rotate incorrectly when dragged. Fixed.
